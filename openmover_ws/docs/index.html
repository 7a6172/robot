Two stacks, one workspace

Robot core (openmover)

The production robot stack: HAL + mode servers, Cartographer SLAM/localization, a custom costmap-based navigation stack, dual-LiDAR drivers, and the teleop/workload orchestration. This is what runs on the real robot and in the openmover simulation world.

Warehouse demo (warehouse_simulation)

A self-contained Pioneer3DX demo used to validate the migration: Gazebo Harmonic + ros_gz bridge + slam_toolbox + Nav2 + a ported keyboard teleop. Moving pedestrians are perceived by the LiDAR and avoided by Nav2 (no physics proxies).

Hardware note

Compiler parallelism must match your RAM: on 16 GB hosts build with -j2, on smaller machines with -j1. A full-parallel build can exhaust memory and freeze the system. The Build guide has the full table, and tools/setup.sh picks a safe setting automatically.
